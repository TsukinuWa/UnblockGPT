## 🤖 What it covers

Unblock GPT is a practical Firefox add-on for people who rely on multiple AI assistants and don't want to lose them to a network hiccup. It routes the following services through an HTTPS proxy inside Firefox:

- **ChatGPT** — `chatgpt.com`, `openai.com`
- **Claude** — `claude.ai`
- **Gemini** — `gemini.google.com`
- **Perplexity** — `perplexity.ai`
- **Mistral** — `mistral.ai`
- **OpenRouter** — `openrouter.ai`
- **Character.AI** — `character.ai`

Each session stays encrypted, the server side of the request stays masked and a block is noticed before it lands in the middle of a conversation.

**No setup wizard, no separate client** — install the add-on and the sites open as usual in your Firefox tab.
